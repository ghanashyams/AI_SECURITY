# AI_SECURITY
A working reference for analysing and monitoring the security of tool-using AI agents, anchored on Claude Code as the implementation example. It covers twelve threat classes specific to agentic systems — indirect prompt injection, tool poisoning, rug pulls, the lethal trifecta, config supply-chain compromise and others — then maps each to where it can be caught: the seven observable surfaces of a Claude agent, twelve static analysis techniques applied to configuration and natural-language artifacts before execution, fourteen runtime techniques built on lifecycle hooks and telemetry, and twelve behavioural detection signals. It surveys the open-source tooling that exists for each, alongside the rule formats, OWASP taxonomies and benchmarks the ecosystem has converged on, and closes with eight problems nobody has solved yet. Everything carries a stable ID so individual items can be expanded independently, with a reference taint-tracking hook and a layered defence architecture in the appendices.
